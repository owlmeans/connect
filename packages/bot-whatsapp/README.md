# @owlmeans/bot-whatsapp

The WhatsApp plugin of OwlMeans chat bots: a `BotPlatformPlugin` for `@owlmeans/server-bot` over
the WhatsApp Cloud API (Graph): the phone number is verified, Meta's GET handshake answers `hub.challenge`, every delivery's `X-Hub-Signature-256` is checked over the raw body, and text messages, replies and reactions are sent; the webhook is set up by hand in the Meta app (the connection's setup steps carry the callback URL and the generated verify token). It ships the platform's descriptor (`WHATSAPP_DESCRIPTOR` — credentials with their labels and
hints in eight languages, receive modes, actions, setup hint) that the
`@owlmeans/web-bot` panels draw through `platform.list`, and an API-faithful mock the platform's tests,
the runtime smoke and end-to-end runs use. It lives in OwlMeans connect because it names a provider;
the bot runtime and contract it plugs into are in common, which never depends on it.

## Installation

```bash
bun add @owlmeans/bot-whatsapp@^0.2.0-alpha.0
```

## Usage

Registration is explicit — importing the package registers nothing:

```typescript
import { makeBotService } from '@owlmeans/server-bot'
import { whatsappBotPlatform } from '@owlmeans/bot-whatsapp'

export const makeService = () => makeBotService({
  secret: () => process.env.APP_SECRET ?? '',
  platforms: [whatsappBotPlatform],          // beside the other platforms the product supports
})

// or, on a context whose bot service may not exist yet:
import { appendWhatsAppBotPlatform } from '@owlmeans/bot-whatsapp'
appendWhatsAppBotPlatform(context)
```

## The platform

| | |
|---|---|
| Id (stored, in the hook URL) | `whatsapp` (`WHATSAPP_PLATFORM`) |
| Credentials | `accessToken`, `phoneNumberId`, `appSecret`, `verifyToken` (generated by the server) |
| Receive | webhook (manual) |
| Actions | reply, send, react — no delete, mute or ban |
| Refusals | `WhatsAppApiError` (`bot:platform:whatsapp:<Graph code>:<message>`, `code`, `status`) — subclasses of `BotErrorPlatform`, travelling under its type name |
| Options | `makeWhatsAppBotPlatform({ … })`: `base`, `version` — the Graph host and version |

## API

- `whatsappBotPlatform` — the ready instance; `makeWhatsAppBotPlatform(options?)` — a configured one;
  `appendWhatsAppBotPlatform(context, options?, alias?)` — register on the context's bot service
- `WHATSAPP_PLATFORM`, `WHATSAPP_DESCRIPTOR`, `WHATSAPP_CREDENTIALS`, `WHATSAPP_HINT`, `whatsappSignatureHelper` and the protocol constants
- the native payload types and the plugin's options

The `bot-whatsapp` skill covers every API call the plugin makes, its normalization and its mock; the
`server-bot` skill (common) covers the plugin interface, the mock transport and the runtime.

## Related packages

- `@owlmeans/server-bot` — the bot runtime this plugs into (common)
- `@owlmeans/bot` — the contract: the descriptor, connections, updates, the errors (common)
- `@owlmeans/web-bot` — the panels that draw the descriptor (common)
